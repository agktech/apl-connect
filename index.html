Settings — Appwrite (optional, later)

Do NOT paste any password here. The owner creates a free Appwrite Cloud project, then pastes only the Endpoint, Project ID, Database ID and Collection IDs below. If these are blank, the app stays in DEMO mode and still works fully.

When Appwrite is configured, login will first try Appwrite email/password auth, and readings will be saved to Appwrite as well as locally. Role comes from the user record in the Users collection; if that lookup fails, the user is treated as Operator. Archive to Supabase / R2 is Phase 2, not in this version — every record already has an archived flag and archiveDate field ready for later.
